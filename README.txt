HOW TO CONNECT GOOGLE ANALYTICS 4
---------------------------------
1. Create a GA4 property in Google Analytics.
2. Create a Web data stream.
3. Copy the Measurement ID. It will look like: G-XXXXXXXXXX
4. Open EACH HTML file in a text editor.
5. Search for: G-XXXXXXXXXX
6. Replace BOTH occurrences with your own Measurement ID.
7. Save the files.
8. Upload the whole folder to a web host such as GitHub Pages, Netlify, Cloudflare Pages,
   or another static hosting service.
9. Open the published website.
10. In GA4, open Reports > Realtime and visit different pages to generate activity.

IMPORTANT
---------
Opening the HTML files only from your computer (file://...) is not the best way to test GA4.
Publish the site online first so it has a normal https:// web address.
